## 🇷🇺 Что нового

Тихий релиз: чинит уведомления об упоминаниях и убирает браузерное меню там, где оно вылезало.

### Исправлено
- **Упоминания перестали путать почту с обращением.** Адрес вроде `user@super.dev` в сообщении
  больше не звенит уведомлением «вас упомянули» тому, у кого имя `super`.
- **Упоминание в конце фразы теперь доходит.** Раньше «спроси у @super.» (с точкой на конце)
  звенело в приложении, но пуш на телефон не уходил — теперь уходит.
- **Правый клик по аватарам и значкам больше не открывает меню браузера** («Сохранить изображение»,
  «Отправить вкладку на устройство»). На картинках, которые кто-то скинул в чат, меню «Сохранить»
  осталось — у них к тому же есть своя кнопка загрузки.
- Пункт «Упомянуть» в меню участника вставлял отображаемое имя вместо логина — из-за этого
  упоминание могло никого не позвать. Теперь вставляет логин.
- Подсветкой упоминания помечается только то, что реально кого-то уведомит: `@Маша` кириллицей
  больше не подсвечивается (имён с кириллицей не бывает, и подсветка вводила в заблуждение).

## 🇬🇧 What's new

A quiet release: fixes mention notifications and stops the browser menu from popping where it shouldn't.

### Fixed
- **Mentions no longer confuse an email with a call-out.** An address like `user@super.dev` in a
  message no longer rings a "you were mentioned" notification for the user named `super`.
- **A mention at the end of a sentence now gets through.** Previously "ask @super." (with a trailing
  dot) rang in-app but never reached the phone as a push — now it does.
- **Right-clicking avatars and icons no longer opens the browser menu** ("Save image", "Send tab to
  your devices"). On images someone posted in chat the "Save" menu stays — and those already have
  their own download button.
- The "Mention" item in the member menu inserted the display name instead of the username, so the
  mention could reach no one. It now inserts the username.
- Mention highlighting now marks only what will actually notify someone: a Cyrillic `@Маша` is no
  longer highlighted (usernames are never Cyrillic, so the highlight was misleading).
