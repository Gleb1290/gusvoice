## 🇷🇺 Что нового

Мобильный фикс: в текстовом канале строка ввода уезжала за край экрана.

### Исправлено
- **Строка ввода на телефоне больше не вылезает за экран.** После того как в неё добавились кнопки
  голосового, стикеров и опроса, поле ввода вместе с кнопкой отправки и нижней панелью уезжало
  вправо за край. Теперь всё помещается: пока набираешь текст, второстепенные кнопки
  (голосовое / стикеры / опрос) прячутся и поле разворачивается на всю ширину, а на пустом поле
  они снова на месте.

## 🇬🇧 What's new

A mobile fix: the message input ran off the edge of the screen in text channels.

### Fixed
- **The message bar on phones no longer runs off-screen.** After the voice, sticker and poll buttons
  were added to it, the input field — along with the send button and the bottom bar — was pushed off
  the right edge. It fits now: while you type, the secondary buttons (voice / stickers / poll) hide
  so the field expands to full width, and they reappear once the field is empty.
