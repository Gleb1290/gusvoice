## 🇷🇺 Что нового

- **До четырёх показов в одном окошке «картинка в картинке».** Окошко уже открыто — кнопка ⧉ на другом показе
  добавляет его туда же, а не открывает второе окно. Два показа встают рядом, три-четыре — сеткой; нажали на кадр —
  он крупно, остальные полосой, нажали ещё раз — снова сеткой. Пятый показ заменяет самый старый. У каждого кадра —
  ник, громкость, выбор качества и «Убрать из окошка»; «Вернуться в приложение» возвращает все показы на сцену. Когда
  стример выключает показ, из окошка уходит только его кадр; убрали последний — окошко закрывается.
- **Федерация включается из админ-панели.** Во вкладке «Федерация» — тумблеры «Федерация» и «Личные сообщения с
  другими инстансами»: без правки `.env` и без перезапуска сервера. Пароль к ключу инстанса сервер заводит и хранит
  сам — бэкапьте базу вместе с каталогом `fed-keys`. Если федерация задана в `.env`, главнее она, и тумблер это
  показывает.

## 🇬🇧 What's new

- **Up to four screen shares in one picture-in-picture window.** With the window already open, the ⧉ button on another
  share adds it to the same window instead of opening a second one. Two shares sit side by side, three or four form a
  grid; click a share to enlarge it with the rest in a strip, click again to go back to the grid. A fifth share
  replaces the oldest. Each share has the streamer's name, volume, quality and "Remove from window"; "Back to app"
  returns all shares to the stage. When a streamer stops sharing, only their share leaves the window; remove the last
  one and the window closes.
- **Federation is turned on from the admin panel.** The Federation tab has "Federation" and "Direct messages with
  other instances" toggles — no `.env` edits and no server restart. The server creates and stores the instance key
  password itself, so back up the database together with the `fed-keys` folder. If federation is set in `.env`, that
  setting wins, and the toggle shows it.
