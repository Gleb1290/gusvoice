## 🇷🇺 Что нового

- **Файлы можно перетащить в переписку прямо из проводника.** В приложении для компьютера бросок файлов не работал — ни в
  личных сообщениях, ни в каналах. Теперь, пока файл над перепиской, она вся становится зоной броска: сверху — отправить
  без сжатия, снизу — быстро. Файл можно бросить и на беседу в списке слева.
- **Чужие показы экрана больше не открываются сами.** Раньше в видах «Фокус» и «Сбоку» первый показ в канале открывался
  автоматически, со звуком. Теперь смотреть начинают только по клику на карточку, как в Discord. Пока ничего не выбрано,
  крупно тот, кто говорит.

## 🇬🇧 What's new

- **Drag files into a chat straight from Explorer.** In the desktop app, dropping files didn't work — neither in direct
  messages nor in channels. Now, while a file is over the chat, the whole chat becomes a drop area: top — send without
  compression, bottom — send quickly. You can also drop a file onto a conversation in the list on the left.
- **Other people's screen shares no longer open on their own.** In the "Focus" and "Side" views the first share in a
  channel used to open automatically, with sound. Now you start watching only by clicking its card, like Discord. While
  nothing is picked, whoever is talking is shown large.
