## 🇷🇺 Что нового

- Владельцы серверов могут обновиться из прежней веб-панели. Переход сохраняет настройки Caddy и LiveKit. После перезапуска панель показывает установленную версию, а при сбое позволяет повторить попытку.
- Обновлены серверные компоненты, включая PostgreSQL 16.16, Redis 7.4.12 и стабильный LiveKit 1.13.11. Проверена передача голоса и экрана между новым и предыдущим публичным веб-клиентом.
- Клиент спрашивает подтверждение при открытии ссылки с некорректным международным доменным именем.

## 🇬🇧 What's new

- Server owners can upgrade from the previous web admin panel while keeping their Caddy and LiveKit settings. After restart, the panel shows the installed version and offers a retry if the update fails.
- Server components now include PostgreSQL 16.16, Redis 7.4.12 and stable LiveKit 1.13.11. Voice and screen sharing were tested between the new and previous public web clients.
- Opening a link with a malformed internationalised domain name prompts for confirmation.
