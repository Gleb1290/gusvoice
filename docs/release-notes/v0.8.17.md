## 🇷🇺 Что нового

- **Файлы в личных сообщениях теперь закрыты.** Раньше фото, голосовое или файл из ЛС лежали по постоянной ссылке,
  и открыть их мог любой, к кому эта ссылка попала. Теперь у каждого из двух собеседников своя ссылка, постороннему
  она не откроется, а «Удалить у обоих» стирает и сам файл. (#213)
- **Длинная переписка больше не тормозит.** В беседе или канале на тысячи сообщений каждая набранная буква
  перерисовывала всю ленту, и поле ввода подтормаживало. Теперь буква появляется сразу, а старые сообщения
  подгружаются быстрее.
- **Личные сообщения переехали на новое хранилище.** Внешне всё как было — это основа для следующих шагов:
  переписка, которая открывается мгновенно и не теряет сообщения при плохой связи. (#211)

### Исправлено
- Продление анимированного аватара могло списать монеты дважды, если запрос повторился.
- На сервере без федерации вкладка «Федерация» в админке показывала «Not Found». Теперь там сказано, что федерация
  выключена и как её включить.

### Стоит знать
- После смены пароля или «Выйти на всех устройствах» файлы в уже открытой переписке перестают открываться и на этом
  устройстве, пока переписку не открыть заново. Так украденное устройство теряет доступ к файлам вместе с входом.

### Для тех, кто держит свой сервер
- Файлам ЛС нужен второй, закрытый бакет. Со встроенным хранилищем коробки делать ничего не надо: сервер сам создаёт
  `<MINIO_BUCKET>-private` без публичного доступа. Если у вас внешний S3 и ключ даёт доступ только к одному бакету —
  создайте второй бакет без публичной политики и укажите его в `MINIO_PRIVATE_BUCKET`, иначе загрузка файлов в ЛС
  будет выключена.
- Ссылки на файлы ЛС строятся от `PUBLIC_API_URL` (пусто — берётся `VITE_API_URL`).
- Обновлены серверные зависимости с известными уязвимостями (`nodemailer`, `fast-uri`).

## 🇬🇧 What's new

- **Files in direct messages are now private.** A photo, voice message or file from a DM used to sit at a permanent
  link that anyone who got hold of it could open. Now each of the two people gets their own link, it won't open for
  anyone else, and "Delete for both" removes the file itself. (#213)
- **Long chats no longer lag.** In a conversation or channel with thousands of messages, every typed letter used to
  redraw the whole feed, and the input box stuttered. Letters now appear instantly, and older messages load faster.
- **Direct messages moved to new storage.** Nothing looks different yet — this is the groundwork for what comes next:
  chats that open instantly and don't lose messages on a bad connection. (#211)

### Fixed
- Extending the animated avatar could charge coins twice if the request was repeated.
- On a server without federation, the admin "Federation" tab showed "Not Found". It now says federation is off and
  how to turn it on.

### Good to know
- After changing your password or using "Sign out on all devices", files in an already open chat stop opening on
  that device too, until you open the chat again. This way a stolen device loses access to files together with the
  sign-in.

### For self-hosters
- DM files need a second, private bucket. With the box's built-in storage there is nothing to do: the server creates
  `<MINIO_BUCKET>-private` itself, with no public access. If you use external S3 and your key only reaches one bucket,
  create a second bucket without a public policy and set it in `MINIO_PRIVATE_BUCKET`; otherwise file uploads in DMs
  stay disabled.
- Links to DM files are built from `PUBLIC_API_URL` (empty means `VITE_API_URL`).
- Server dependencies with known vulnerabilities were updated (`nodemailer`, `fast-uri`).
