## 🇷🇺 Что нового

- **Голосовой канал больше не мерцает в узком окне.** На некоторых ширинах окна сетка камер, стримов и участников без конца
  перестраивалась между одной и двумя колонками. Теперь раскладка устойчива: колонки меняются, только когда места
  действительно стало больше или меньше.

## 🇬🇧 What's new

- **Voice channels no longer flicker in a narrow window.** At certain window widths the grid of cameras, streams and
  participants kept rebuilding between one and two columns. The layout is stable now: columns change only when there is
  genuinely more or less room.
