## 🇷🇺 Что нового

- **🔴 Сообщение с `*курсивом*` вешало приложение.** Любой текст с курсивом, жирным, зачёркнутым или
  спойлером уводил разбор в бесконечный цикл: вкладка съедала память и переставала отвечать —
  причём у **всех**, кто открывал канал с таким сообщением, а не только у автора. Ошибка приехала
  вместе с оформлением сообщений в `v0.5.67`. Обновиться стоит всем
- **Больше не выкидывает раз в неделю.** Токен жил семь дней от момента входа, поэтому вылетали даже
  те, кто заходит каждый день. Теперь отсчёт идёт от последней активности: «протух» означает
  «неделю не заходил»

### Внутреннее

Добавлены базовые тесты во все пакеты и включены в CI-гейт: порядок наложения прав (где ошибка
означает доступ к чужому каналу), фильтр внешних запросов, разбор страниц, экранирование текста
сообщений, соответствие набора эмодзи и кодов набора. Зависание нашлось именно прогоном — падением
по памяти на длинном сообщении. Заодно тесты выявили три дублирующихся кода эмодзи (при наборе
`:ура:` результат был лотереей) и повтор символа в наборе.

## 🇬🇧 What's new

- **🔴 A message with `*italics*` froze the app.** Any text with italic, bold, strikethrough or a
  spoiler sent the parser into an infinite loop: the tab ate memory and stopped responding — for
  **everyone** who opened the channel, not just the author. The bug shipped with message formatting
  in `v0.5.67`. Everyone should update
- **No more weekly logouts.** Tokens expired seven days after login, so even daily users got kicked
  out. Expiry now counts from your last activity: "expired" means "away for a week"

### Internal

Basic tests added across all packages and wired into the CI gate: permission overwrite ordering
(where a mistake means access to someone else's channel), the outbound-request filter, page parsing,
message text escaping, and emoji set/shortcode parity. The freeze was found by running them — an
out-of-memory crash on a long message. The same run surfaced three duplicate emoji shortcodes
(typing `:ура:` was a coin flip) and a duplicated symbol in the picker.
