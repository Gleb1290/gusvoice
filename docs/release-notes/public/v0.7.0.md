## 🇷🇺 GusVoice v0.7.0 — код открыт

Это первый выпуск, в котором **опубликован весь исходный код** под лицензией **AGPLv3**. Сводка накопилась
с прошлой публичной сборки (v0.6.39), поэтому сгруппирована по темам, а не по версиям.

### Открытый код
- Сервер, веб-клиент, десктоп и Android — в этом же репозитории. Лицензия **AGPL-3.0-only** (`LICENSE`),
  чужие компоненты и разрешение для NVIDIA Video Codec SDK — в `LICENSING.md`.
- Как собрать и как прислать правку — `CONTRIBUTING.md` (можно по-русски), соглашение для авторов — `CLA.md`,
  об уязвимостях — приватно, `SECURITY.md`.
- Как устроен проект — `docs/ARCHITECTURE.md`, как поднять у себя — `docs/SELF-HOSTING.md`.

### Установка и обслуживание сервера
- **Первый запуск без консольных вопросов:** установщик спрашивает домен и способ выхода в интернет, всё
  остальное — супер-админ, название инстанса, почта, кто может регистрироваться, первый сервер и проверка
  голоса — задаётся в браузере по коду установки.
- **Кнопка «Обновить» в админ-панели:** видно установленную и свежую версию, обновление идёт по шагам,
  страница переживает перезапуск. Сервер к Docker не допущен — заявку выполняет служба на самой машине.
- **Обновление сохраняет копию базы** в `.gusvoice-backups/` (хранятся пять последних).
- **Встроенное хранилище** переведено с MinIO (его больше не публикуют) на versitygw; у ранее поставленных
  коробок медиа переносится автоматически, один раз.
- Политика регистрации: все · все с одобрением админа · только по приглашению.

### Голос, показ экрана, звуки
- Выдернул наушники или микрофон — разговор переходит на то, что осталось, а не обрывается.
- Карточка человека в голосе открывается кликом, показывает роли; по кадру в карточке можно перейти на показ.
- Починены: падение показа, из-за которого второй слой качества отключался у всех навсегда; пропажа кнопки
  саундборда во время показа; срезанная обводка говорящего; потеря серверных событий после обновления сервера.
- Саундборд: имя звука под мышью, поддержка файлов `m4a`, отказ исполняемых файлов под видом звука.

### Экономика GusCoins
- Пересчитанные по живым данным ставки и лестница званий, честные тексты про «отошёл», журнал кошелька
  с выгрузкой, подсказки «кто кого» поверх игры и стрима, анимированный аватар до 4 МБ.
- Владелец сервера может назначить свою цену анимированного аватара, но не ниже цены держателя инстанса.

### Безопасность и надёжность
- Закрыта возможность обойти ограничения «по адресу» подделкой заголовка прокси.
- Сервер не стартует с секретом-заглушкой из примера конфигурации.
- Обновлена почтовая библиотека (HIGH-уязвимость), закреплены версии Postgres и Redis.
- Удаление аккаунта обезличивает запись: логин и почта освобождаются, переписка остаётся.
- Интерфейс больше не гаснет молча при ошибке, окно можно закрыть, даже если страница умерла.

## 🇬🇧 GusVoice v0.7.0 — the source is open

This is the first release with the **whole source code published** under the **AGPLv3**. The summary covers
everything since the previous public build (v0.6.39), grouped by topic rather than by version.

### Open source
- Server, web client, desktop and Android live in this repository. Licence: **AGPL-3.0-only** (`LICENSE`);
  third-party components and the NVIDIA Video Codec SDK exception are listed in `LICENSING.md`.
- How to build and how to send a change — `CONTRIBUTING.md` (English or Russian); the contributor agreement
  is `CLA.md`; security problems go privately through `SECURITY.md`.
- How it is put together — `docs/ARCHITECTURE.md`; how to host it — `docs/SELF-HOSTING.md`.

### Installing and running a server
- **The first run asks almost nothing in the console:** the domain and how the box is reachable. The admin
  account, instance name, mail, registration policy, the first server and a voice check are done in the
  browser with the setup code.
- **An "Update" button in the admin panel:** installed and newest version side by side, progress by steps,
  and the page survives the restart. The backend has no access to Docker — a host service does the work.
- **Updates keep a database copy** in `.gusvoice-backups/` (the five newest are kept).
- **The bundled storage** moved from MinIO (no longer published) to versitygw; boxes installed earlier get
  their media moved into it once, automatically.
- Registration policy: open · admin approval · invite only.

### Voice, screen-share, sounds
- Unplugging headphones or a microphone moves the conversation to whatever is left instead of dropping it.
- A person's card in voice opens on click and shows their roles; the preview in it takes you to their stream.
- Fixed: one crash disabling the second quality layer for everyone forever; the soundboard button
  disappearing during a stream; the speaking ring being clipped; losing server events after a server update.
- Soundboard: full sound name on hover, `m4a` support, executables disguised as sounds rejected.

### GusCoins economy
- Rates and the rank ladder recalibrated on real data, honest wording about the "away" state, a wallet log
  with export, "who tipped whom" prompts over the game and over streams, animated avatars up to 4 MB.
- A server owner can set their own animated-avatar price, but not below the instance holder's price.

### Security and robustness
- Closed a way to bypass per-address limits by forging the proxy address header.
- The server refuses to start with a placeholder secret from the example configuration.
- Mail library updated (HIGH severity), Postgres and Redis pinned to exact versions.
- Deleting an account anonymises the row: the username and e-mail are freed, the conversation stays.
- The interface no longer goes dark silently on an error, and the window closes even if the page died.
