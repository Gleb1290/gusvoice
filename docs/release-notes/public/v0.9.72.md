## 🇷🇺 Что нового

- В настройках «Где я гость» можно заранее подключить запасной сервер по приглашению. Если вы уже вступили, выберите «Подготовить доступ» на каждом устройстве, с которого хотите заходить. Приложение покажет, подтвердил ли сервер ваш доступ.
- Если домашний инстанс недоступен, при запуске можно сразу выбрать сохранённый инстанс. Для входа к соседу нужна действующая гостевая сессия на этом устройстве.
- Браузер сохраняет интерфейс после загрузки обновлённого сайта. Когда домашний сайт недоступен, его можно снова открыть по тому же адресу в том же браузере и перейти на доступный инстанс.
- В приложении для ПК можно сразу печатать после выбора личной переписки.

## 🇬🇧 What's new

- Under “Где я гость” in Settings, use an invite to set up a backup server. If you already belong to the server, select “Подготовить доступ” on each device you want to use. The app checks your access with the server.
- If your home instance is unavailable, you can choose a saved instance as soon as the app opens. Visiting a peer requires a valid guest session on that device.
- After loading the updated site, your browser saves the app interface. If the home site goes down, reopen the same address in the same browser to reach an available instance.
- On desktop, you can start typing as soon as you select a direct message conversation.
