# GusVoice v0.9.51

Прошлая публичная сборка — **v0.9.15** (25.10). Главное в этой: **боты в стиле Telegram** и готовые SDK для них в npm и
PyPI; смена окна или экрана прямо во время показа; исправления личных сообщений по проверке безопасности.

*(English version below / английская версия ниже.)*

---

## ⚠️ Для тех, кто держит свой сервер

- **Боты по умолчанию выключены.** Пока супер-администратор не включит их в админ-панели, токены ботов не принимаются и
  создать бота нельзя. Справочник — `docs/bots.ru.md`, схема API — `/api/bot/v1/openapi.json` на вашем сервере.
- Четыре новые миграции базы (боты, кнопки ботов, «история для новых» в группах, боты на серверах) применяются сами при
  старте. Новых переменных в `.env` нет.
- Обновление — `./update.sh` или кнопка «Обновить» во вкладке «Инстанс» админ-панели; после обновления людям —
  перезапустить приложение или обновить страницу.

## 🤖 Боты

- **Боты как в Telegram** — аккаунты, которыми управляет программа. Создаются в «Настройки → Мои боты». Бот отвечает в
  личных сообщениях (первым написать не может — человек сам жмёт «Старт»), показывает кнопки под сообщениями и меню
  команд по «/».
- **Боты на серверах.** Админ добавляет бота на сервер: у бота своя роль, права не выше, чем у добавившего, и по умолчанию
  он видит только обращённые к нему сообщения.
- **Боты в голосе.** Бот может играть звук в голосовом канале, но людей не слышит; модератор может его заглушить или
  отключить.
- **SDK:** `npm i @gusvoice/bot` (TypeScript, без зависимостей; голос — `@gusvoice/bot-voice`) и `pip install gusvoice-bot`
  (Python, только стандартная библиотека). Готовые примеры под MIT — `examples/bots`.

## 🖥️ Показ экрана

- **Смена окна или экрана на лету.** Во время показа есть кнопка «Сменить окно или экран» — выбираешь другое окно, экран
  или камеру, и показ продолжается без остановки и без переподключения зрителей. Звук приложения переходит вместе с окном.
- Показ окна с «Максимальным качеством» виден зрителям (в промежуточной сборке 0.9.50 он был чёрным).

## 💬 Личные сообщения

- **Исправления по проверке безопасности.** Ссылки на фото и файлы живут ограниченное время; реакции — до трёх на сообщение
  и только эмодзи; уведомления без ключей шифрования приходят без текста; фото группы видно только её участникам.
- **«История для новых участников»** — настройка создателя группы: видят ли новые участники сообщения до своего
  добавления. У новых групп история по умолчанию скрыта, у уже существующих — видна, как раньше.

## 📱 Телефон и ПК

- Телефон: после отправки Caps Lock экранной клавиатуры сбрасывается, а подсказки эмодзи пропадают.
- ПК: панель эмодзи, открытая наведением, больше не закрывается, когда ведёшь на неё мышь.
- Android: уведомление больше не показывает набор непонятных символов (редкий сбой расшифровки пуша).
- ПК: обновление в один проход — после «Обновить» приложение сразу качает новую версию.

# 🇬🇧 GusVoice v0.9.51

The previous public build was **v0.9.15** (25.10). The highlights: **Telegram-style bots** with ready SDKs on npm and
PyPI; switching the shared window or screen in the middle of a share; direct-message fixes from a security review.

## ⚠️ If you host your own server

- **Bots are off by default.** Until the super-administrator turns them on in the admin panel, bot tokens are rejected and
  nobody can create a bot. Reference: `docs/bots.md`; the API schema is served at `/api/bot/v1/openapi.json` on your server.
- Four new database migrations (bots, bot buttons, "history for new members" in groups, bots on servers) apply by
  themselves at startup. No new `.env` variables.
- Update with `./update.sh` or the Update button in the admin panel's Instance tab; afterwards people should restart the
  app or reload the page.

## 🤖 Bots

- **Telegram-style bots** — accounts driven by a program. Create one in Settings → My bots. A bot answers in direct
  messages (it can't write first — the person presses Start), shows buttons under its messages and a command menu on "/".
- **Bots on servers.** An admin adds a bot to a server: it gets its own role, never with more permissions than the admin who
  added it, and by default it only sees messages addressed to it.
- **Bots in voice.** A bot can play audio in a voice channel but never hears people; a moderator can mute or disconnect it.
- **SDKs:** `npm i @gusvoice/bot` (TypeScript, no dependencies; voice via `@gusvoice/bot-voice`) and
  `pip install gusvoice-bot` (Python, standard library only). Ready-made examples under MIT in `examples/bots`.

## 🖥️ Screen sharing

- **Switch the window or screen on the fly.** While sharing, press "Change window or screen" and pick another window,
  screen or camera — the share keeps going, viewers don't reconnect. Application audio follows the window.
- Sharing a window with "Maximum quality" is visible to viewers (in the intermediate 0.9.50 build it was black).

## 💬 Direct messages

- **Fixes from a security review.** Links to photos and files expire; reactions are limited to three per message and emoji
  only; notifications without encryption keys arrive without the text; a group's photo is visible only to its members.
- **"History for new members"** — a group creator's setting: whether new members see messages from before they were added.
  New groups hide the history by default; existing groups keep showing it, as before.

## 📱 Phone and desktop

- Phone: after you send, the on-screen keyboard's Caps Lock is reset and emoji suggestions disappear.
- Desktop: the emoji panel opened by hovering no longer closes when you move the mouse onto it.
- Android: notifications no longer show a string of garbled characters (a rare push decryption glitch).
- Desktop: one-step update — after "Update" the app downloads the new version right away.
