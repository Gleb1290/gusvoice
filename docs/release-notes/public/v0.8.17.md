# GusVoice v0.8.17

Прошлая публичная сборка — **v0.8.2** (23 сентября). Главное с тех пор: **десктоп снова запускается без видеокарты
NVIDIA**, **показ экрана почти не мешает игре**, а **личные сообщения** стали заметно ближе к Telegram — с полной
историей, чёрным списком, удалением у обоих и закрытыми файлами.

*(English version below / английская версия ниже.)*

---

## 🖥 Компьютеры без NVIDIA

- **Приложение запускается на машинах с AMD или встроенной графикой.** Сборки с конца июня по v0.8.2 включительно на
  таких компьютерах не стартовали вовсе: Windows писал, что не найден `nvcuda.dll`. Теперь запускаются, а показ экрана
  там кодирует процессор.

## 💬 Личные сообщения

- **Вся переписка, а не последние 50 сообщений.** Листаешь вверх — подгружается дальше.
- **Чёрный список.** Кнопка в шапке беседы. Заблокированный об этом не узнаёт: у него всё выглядит как обычно, а до
  тебя не доходят ни его новые сообщения, ни «печатает», ни пуши. Список — Настройки → Аккаунт и безопасность →
  «Заблокированные».
- **Удалить у себя или у обоих.** У своего сообщения — галочка «Также удалить для …», чужое можно удалить только у себя.
- **Файлы в ЛС закрыты.** Раньше фото, голосовое или файл из ЛС лежали по постоянной ссылке, которую мог открыть любой,
  к кому она попала. Теперь у каждого собеседника своя ссылка, постороннему она не откроется, а «Удалить у обоих»
  стирает и сам файл. После смены пароля или «Выйти на всех устройствах» ссылки гаснут везде, в том числе в уже
  открытой переписке — пока её не открыть заново.
- **Текст пуша на телефоне зашифрован** — сервер уведомлений видит только шифр.
- **На компьютере клик по уведомлению о ЛС открывает беседу**, а значок в панели задач мигает, пока не посмотришь.
- **Несколько строк в сообщении**: на компьютере Shift+Enter — перенос, Enter — отправить; на телефоне Enter переносит
  строку, отправка — кнопкой. Нажатие на аватар или имя открывает профиль.
- Исправлено: счётчик непрочитанного больше не застревает на «1»; беседа не отмечается прочитанной, если ты её не видел;
  нет звука о новом сообщении в беседе, которую читаешь; реакция не удваивается.
- ЛС переехали на новое хранилище. Внешне всё как было — это основа для переписки, которая открывается мгновенно и не
  теряет сообщения при плохой связи.

## ⚡ Быстрее

- **Длинная переписка не тормозит.** В беседе или канале на тысячи сообщений каждая буква раньше перерисовывала всю
  ленту. Теперь буква появляется сразу, а старые сообщения подгружаются быстрее.
- **Приложение меньше грузит компьютер в голосе.** Библиотека голоса крутила лишний цикл отрисовки на каждого
  собеседника — его больше нет. Под полноэкранной игрой и в трее окно не рисуется вовсе.
- **«Оптимизированный режим»** (Настройки → Вид) для слабых компьютеров: интерфейс перестаёт двигаться сам,
  анимированные аватары оживают только при наведении. Звук, показ и сообщения работают как обычно.

## 🎧 Показ экрана и игры

- **Качество чужого показа выбирается по-настоящему.** Показ идёт тремя слоями — полное, среднее (720p с той же
  плавностью) и экономное; в меню ⚙ видны только те, что есть у этого показа, с разрешением. Если сервер перевёл тебя
  на слой хуже из-за скорости соединения, приложение скажет об этом.
- **Под игрой — через видеокарту целиком (NVIDIA, H.264).** Захват, перевод цвета, уменьшение под каждый слой и
  кодирование идут внутри видеокарты. В игре, которая грузит видеокарту до упора, показ держит 60 кадров вместо 30–40,
  процессор почти не тратится. Выключается переключателем «Показ через видеокарту».
- **Полное качество получает весь битрейт**: в локальной сети — сразу, через интернет разгоняется быстрее.
- **Один зритель со слабым интернетом больше не портит картинку остальным.**
- **Показ всего экрана стабильнее в играх**: снимается тем же способом, что в OBS, курсор над игрой не дёргается.
- **Зрители видят твой курсор** (раньше его не было вовсе). Выключается галочкой «Показывать курсор».
- Слои, которые никто не смотрит, не кодируются; карточки показов в канале не будят кодировщик показывающего;
  обновление или перезапуск посреди показа завершают его штатно.

## 🎙 Голос

- **Обводка загорается и у тех, кто говорит тихо**: приложение само узнаёт, как звучит тишина у каждого, и зажигает
  обводку, когда голос заметно громче неё.
- **Порог голоса по умолчанию — 1 %** (было «выкл», и новые люди заходили с шумом комнаты в эфире). Ползунок — от 1 до
  60 %, Настройки → Устройства и звук.

## 🎛 Интерфейс и прочее

- Настройки сервера и канала устроены как остальные: разделы слева с подписями. Роли и участники — внутри настроек
  сервера, кнопка 👥 открывает их сразу.
- **На телефоне** клавиатура больше не сдвигает экран, правка сообщения — в основном поле, внутри переписки нет нижней
  панели вкладок, подсветка не «залипает» после касания, служба уведомлений на Android 15 не засыпает через 6 часов.
- Анимированный аватар оплачивается не больше чем на 60 дней вперёд; продление больше не может списать монеты дважды.

## 🛡 Для держателей инстансов

- **Файлам ЛС нужен второй, закрытый бакет.** Со встроенным хранилищем коробки делать ничего не надо: сервер сам создаёт
  `<MINIO_BUCKET>-private` без публичного доступа. Если у вас внешний S3 и ключ даёт доступ только к одному бакету —
  создайте второй без публичной политики и укажите его в `MINIO_PRIVATE_BUCKET`, иначе загрузка файлов в ЛС будет
  выключена. Ссылки на файлы строятся от `PUBLIC_API_URL` (пусто — `VITE_API_URL`).
- Старые ЛС переносятся в новое хранилище сами, при первом запуске после обновления (миграции применяются при старте).
  Сделайте бэкап базы перед обновлением — как перед любым большим.
- На сервере без федерации вкладка «Федерация» в админке показывала «Not Found» — теперь там сказано, что федерация
  выключена и как её включить.
- Обновлены серверные зависимости с известными уязвимостями (`nodemailer`, `fast-uri`).

## Как обновиться

- **Сервер:** `./update.sh` в каталоге установки — или кнопка «Обновить» в админ-панели, если она включена.
- **Десктоп и Android обновляются сами.** Установщики ниже — для новых машин. Если десктоп v0.8.2 у вас не запускался
  (нет NVIDIA), поставьте установщик ниже вручную.
- **Свежая установка:** `curl -fsSL https://raw.githubusercontent.com/Gleb1290/gusvoice/main/install.sh | bash`

# GusVoice v0.8.17 (English)

The previous public build was **v0.8.2** (23 September). The big things since: **the desktop app starts again without
an NVIDIA graphics card**, **screen sharing barely gets in your game's way**, and **direct messages** moved a lot closer
to Telegram — full history, a block list, delete for both, and private files.

## 🖥 Computers without NVIDIA

- **The app starts on machines with AMD or integrated graphics.** Builds from late June up to and including v0.8.2 did
  not start on such computers at all: Windows reported that `nvcuda.dll` was not found. They start now, and screen
  sharing there is encoded on the CPU.

## 💬 Direct messages

- **The whole conversation, not just the last 50 messages.** Scroll up and older ones load.
- **Block list.** A button in the conversation header. The blocked person is never told: everything looks normal on
  their side, while their new messages, "typing…" and pushes never reach you. The list is in Settings → Account &
  security → «Заблокированные» (Blocked).
- **Delete for me or for both.** Your own message has an «Также удалить для …» (also delete for …) checkbox; someone
  else's can be deleted only for yourself.
- **DM files are private.** A photo, voice message or file from a DM used to sit at a permanent link that anyone who got
  hold of it could open. Now each person gets their own link, it won't open for anyone else, and "Delete for both"
  removes the file itself. After a password change or "Sign out on all devices" the links stop working everywhere,
  including in an already open chat, until you open it again.
- **Push text on the phone is encrypted** — the notification server only sees ciphertext.
- **On desktop, clicking a DM notification opens the conversation**, and the taskbar icon flashes until you look.
- **Multi-line messages**: on desktop Shift+Enter adds a line and Enter sends; on the phone Enter adds a line and the
  button sends. Tapping an avatar or name opens the profile.
- Fixed: the unread counter no longer gets stuck at "1"; a conversation is no longer marked read when you didn't see it;
  no new-message sound for the conversation you're reading; a reaction no longer doubles.
- DMs moved to new storage. Nothing looks different yet — this is the groundwork for chats that open instantly and
  don't lose messages on a bad connection.

## ⚡ Faster

- **Long chats no longer lag.** In a conversation or channel with thousands of messages, every typed letter used to
  redraw the whole feed. Letters now appear instantly, and older messages load faster.
- **Less load on your computer while in voice.** The voice library ran an extra drawing loop for every person in the
  channel — it's gone. Under a fullscreen game and in the tray the window isn't drawn at all.
- **«Оптимизированный режим» (optimised mode)** in Settings → Appearance, for weaker computers: the interface stops
  moving on its own, and animated avatars come alive only on hover. Voice, sharing and messages work as usual.

## 🎧 Screen sharing and games

- **Viewer quality is a real choice now.** A share is sent in three layers — full, medium (720p at the same smoothness)
  and economy; the ⚙ menu lists only the layers this stream has, with their resolution. If the server moves you to a
  lower layer because of your connection, the app tells you.
- **Under a game it runs entirely on the GPU (NVIDIA, H.264).** Capture, colour conversion, scaling for each layer and
  encoding all happen on the graphics card. In a game that maxes out the GPU the stream holds 60 fps instead of 30–40,
  with almost no CPU cost. Turned off with the «Показ через видеокарту» switch.
- **Full quality gets its whole bitrate**: right away on a LAN, and it ramps up faster over the internet.
- **One viewer with a weak connection no longer spoils the picture for everyone else.**
- **Full-screen sharing is more stable in games**: captured the same way OBS does it, so the cursor over a game no
  longer stutters.
- **Viewers can see your cursor** (it used to be missing). Turned off with «Показывать курсор» (show cursor).
- Layers nobody watches aren't encoded; stream cards in a channel no longer wake the streamer's encoder; updating or
  restarting mid-stream ends the stream properly.

## 🎙 Voice

- **The speaking ring lights up for quiet talkers too**: the app learns what silence sounds like for each person and
  lights the ring when the voice is clearly louder than that.
- **Default voice threshold is 1 %** (it used to be "off", and new people joined with their room noise on air). The
  slider goes from 1 to 60 %, Settings → Devices & sound.

## 🎛 Interface and more

- Server and channel settings are laid out like the rest: sections on the left with a short description. Roles and
  members live inside server settings, and the 👥 button opens them directly.
- **On the phone** the keyboard no longer pushes the screen up, editing happens in the main input, there's no bottom
  tab bar inside a chat, highlights don't stick after a tap, and the notification service on Android 15 no longer falls
  asleep after 6 hours.
- The animated avatar can be paid at most 60 days ahead; extending it can no longer charge coins twice.

## 🛡 For instance owners

- **DM files need a second, private bucket.** With the box's built-in storage there is nothing to do: the server creates
  `<MINIO_BUCKET>-private` itself, with no public access. If you use external S3 and your key only reaches one bucket,
  create a second bucket without a public policy and set it in `MINIO_PRIVATE_BUCKET`; otherwise file uploads in DMs
  stay disabled. File links are built from `PUBLIC_API_URL` (empty means `VITE_API_URL`).
- Existing DMs are moved to the new storage automatically on the first start after the update (migrations apply on
  start). Back up the database before updating, as before any big update.
- On a server without federation, the admin "Federation" tab showed "Not Found" — it now says federation is off and how
  to turn it on.
- Server dependencies with known vulnerabilities were updated (`nodemailer`, `fast-uri`).

## Updating

- **Server:** `./update.sh` in the install directory — or the "Update" button in the admin panel if enabled.
- **Desktop and Android update themselves.** The installers below are for new machines. If desktop v0.8.2 didn't start
  for you (no NVIDIA), install it from below by hand.
- **Fresh install:** `curl -fsSL https://raw.githubusercontent.com/Gleb1290/gusvoice/main/install.sh | bash`
