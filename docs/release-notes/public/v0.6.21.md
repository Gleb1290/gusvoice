## 🇷🇺 Что нового с прошлой публичной сборки

Прошлая публичная сборка была **v0.6.20**. С тех пор вышла одна версия.

- **Клик по ярлыку возвращает уже открытый клиент, а не запускает второй.** Приложение сворачивается
  в трей, окна на панели задач нет — и человек, естественно, жмёт ярлык на рабочем столе. Раньше это
  запускало ещё одну копию GusVoice поверх работающей.
  - Хуже всего было то, что происходило с голосом: две копии заходят на сервер под одним и тем же
    именем, сервер оставляет только последнюю, и первая молча вылетала из разговора. Окно при этом
    оставалось на экране как ни в чём не бывало — со стороны выглядело, будто клиент сам замолчал.
  - Попутно перестают плодиться процессы: каждая лишняя копия тянула за собой свой набор системных
    процессов браузерного движка, и их набиралось по десятку.
  - Теперь ярлык, трей и уже запущенное приложение ведут в одно и то же окно: свёрнутое —
    развернётся, спрятанное в трей — покажется, чужое поверх — выйдет на передний план.

- **Безопасность:** обновлена зависимость `fast-uri` (CVE-2026-18446, host confusion через обратный
  слэш в адресе). Затрагивала разбор адресов на стороне сервера.

## 🇬🇧 What's new since the last public build

The previous public build was **v0.6.20**. One version has shipped since.

- **Clicking the shortcut brings back the client you already have open instead of starting a second
  one.** The app minimises to the tray, so there is no taskbar window to click — and people
  naturally reach for the desktop shortcut. That used to launch another copy of GusVoice alongside
  the running one.
  - The worst part was what it did to voice: two copies join the server under the same name, the
    server keeps only the newer one, and the first silently dropped out of the call. Its window
    stayed on screen as if nothing had happened, so it looked like the client had gone quiet by
    itself.
  - Processes stop piling up as well: every extra copy dragged in its own set of browser-engine
    system processes, and they added up fast.
  - The shortcut, the tray icon and the running app now all lead to the same window: minimised, it
    restores; hidden in the tray, it reappears; behind other windows, it comes to the front.

- **Security:** the `fast-uri` dependency was updated (CVE-2026-18446, host confusion via a
  backslash in the address). It affected address parsing on the server side.
