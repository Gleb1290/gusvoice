## 🇷🇺 Владельцам серверов

Если вы меняли сам `docker-compose.yml`, до первого обновления перенесите свои изменения в `docker-compose.override.yml`. Старый обновлятор заменяет основной файл. Если для push используется встроенный ntfy и нужен откат к его прежней версии, сделайте снимок тома ntfy при остановленном сервисе. Автоматическая резервная копия панели содержит базу PostgreSQL.

- Обновление доступно из веб-панели. Проверен переход со старых панелей с сохранением пользователей, сообщений, вложений и настроек Caddy и LiveKit.
- В комплекте стабильные LiveKit 1.13.11, PostgreSQL 16.16 и Redis 7.4.12. Продолжаем отслеживать два замечания безопасности в медиасервере. [WebRTC](https://github.com/pion/webrtc/security/advisories/GHSA-9pr8-85xc-qhv7) · [DTLS](https://github.com/pion/dtls/security/advisories/GHSA-jm57-r6vj-mwg9)

### Голос, чаты и роли

- Громкость участника и стрима меняется с шагом 1 %. Локальный мут сохраняется после повторного входа, а нота рядом с ботом показывает, что он играет музыку.
- На Android ссылки открываются во внешнем браузере. В каналах только для чтения видна соответствующая плашка. Администратор может сделать текстовый канал тихим для всех.
- Ролям можно задавать собственный цвет, искать права по названию и добавлять сразу нескольких участников. В настройках канала видно, почему конкретному человеку разрешено или запрещено действие.

## 🇬🇧 For server owners

If you edited `docker-compose.yml` directly, move your changes into `docker-compose.override.yml` before your first update. Older updaters replace the base file. If you use bundled ntfy and need a rollback to the previous version, snapshot its volume with ntfy stopped. The panel's automatic backup covers PostgreSQL.

- Upgrade from the web admin panel. Upgrades from older panels were tested with accounts, messages, attachments and custom Caddy and LiveKit settings.
- The box includes stable LiveKit 1.13.11, PostgreSQL 16.16 and Redis 7.4.12. Two media server advisories remain open. [WebRTC](https://github.com/pion/webrtc/security/advisories/GHSA-9pr8-85xc-qhv7) · [DTLS](https://github.com/pion/dtls/security/advisories/GHSA-jm57-r6vj-mwg9)

### Voice, chat and roles

- Adjust participant and stream volume in 1% steps. Local mute persists after rejoining, and a music note shows when a bot is playing.
- Android opens links in an external browser. Read-only channels show a notice, and admins can silence a text channel for everyone.
- Give roles a custom colour, search permissions by name and add several members at once. Channel settings explain which rule grants or denies access for a particular member.
