## 🇷🇺 Что нового

**Исходный код GusVoice открыт** — весь, под лицензией AGPLv3: https://github.com/Gleb1290/gusvoice
Сервер, клиент, десктоп и Android теперь можно читать, собирать самому и присылать правки. Что можно и
чего нельзя — в `LICENSE` и `LICENSING.md`, как прислать изменение — в `CONTRIBUTING.md`.

- **Кнопка «Обновить» в админ-панели.** Супер-админ открывает ⚙ → «Инстанс» и видит установленную версию
  рядом со свежей. Кнопка обновляет сервер сама: показывает шаги, переживает перезапуск и сама
  переподключается. Доступа к Docker у сервера при этом нет — он только оставляет заявку, а выполняет её
  служба на самой машине. Включается один раз командой `sudo ./update.sh --install-updater` (установщик
  делает это сам, если может).

- **Обновление сохраняет копию базы.** Перед перезапуском контейнеров `./update.sh` кладёт копию в
  `.gusvoice-backups/` и хранит пять последних. Как вернуться на прошлую версию — в `docs/SELF-HOSTING.md`.

- **Первый запуск — без консольных вопросов.** Установщик спрашивает только домен и как выходить в
  интернет, а супер-админ, название инстанса, почта, кто может регистрироваться и первый сервер задаются
  в браузере — мастером, который открывается по коду установки.

- **Встроенное хранилище в коробке заменено.** MinIO больше не публикуется его авторами, поэтому свежие
  установки поднимали хранилище с пустого места. Теперь в коробке versitygw, а у тех, кто ставил раньше,
  медиафайлы переносятся в новое хранилище один раз и автоматически при обновлении.

- **Закрыта дыра в ограничениях по адресу.** Клиент мог подделать заголовок с адресом и обойти защиту от
  перебора паролей и другие ограничения «на адрес». Теперь адрес берётся только от доверенного прокси.

- **Сервер не стартует с секретом-заглушкой** из примера конфигурации: раньше инстанс мог тихо работать с
  общеизвестным ключом подписи сессий.

- **Удаление аккаунта обезличивает запись**, а не стирает её: логин и почта освобождаются, переписка
  остаётся на месте и не рассыпается.

## 🇬🇧 What's new

**GusVoice is now open source** — all of it, under the AGPLv3: https://github.com/Gleb1290/gusvoice
The server, the web client, the desktop and the Android app can be read, built and improved by anyone.
See `LICENSE` and `LICENSING.md` for the terms and `CONTRIBUTING.md` for how to send a change.

- **An "Update" button in the admin panel.** The super-admin opens ⚙ → Instance and sees the installed
  version next to the newest release. The button updates the server: it shows the steps, survives the
  restart and reconnects on its own. The backend never gets access to Docker — it only leaves a request
  that a small systemd watcher on the host picks up. Enable it once with
  `sudo ./update.sh --install-updater` (the installer does it for you when it can).

- **Updates keep a copy of the database.** Before recreating containers `./update.sh` saves a dump into
  `.gusvoice-backups/` and keeps the five newest. Rolling back is described in `docs/SELF-HOSTING.md`.

- **First run asks almost nothing in the console.** The installer asks for the domain and how the box is
  reachable; the admin account, instance name, mail, who may register and the first server are set up in
  the browser through a wizard that opens with the setup code.

- **The bundled storage has been replaced.** MinIO is no longer published by its authors, so fresh
  installs came up with nothing behind the media storage. The box now ships versitygw, and boxes
  installed earlier get their media moved into it once, automatically, during the update.

- **Fixed a hole in per-address limits.** A client could forge the forwarded-address header and bypass
  the password brute-force protection and other per-address limits. The address is now taken only from a
  trusted proxy.

- **The server refuses to start with a placeholder secret** from the example configuration — an instance
  could previously run quietly with a well-known session signing key.

- **Deleting an account anonymises the row** instead of erasing it: the username and e-mail are freed
  while the conversation stays readable.
