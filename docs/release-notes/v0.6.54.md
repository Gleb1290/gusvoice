## 🇷🇺 Что нового

- **Найдена причина «пропал звук типа и оверлей».** Симптом знакомый: всё работает, потом внезапно
  перестаёт, и лечится только полным перезапуском приложения. Виновата была не какая-то одна
  функция, а **порядок двух первых сообщений при переподключении**: приложение представлялось
  серверу и тут же, не дожидаясь ответа, просило подписать себя на события. Сервер в этот момент ещё
  проверял вход и просьбу отклонял, а приложение отказ не слушало и считало себя подписанным.

  В итоге после **каждого обновления сервера** человек оставался без всех событий сразу — без звука
  и плашки типа, без щипков, без выстрелов саундборда и без новых сообщений в чате. Баланс монет при
  этом продолжал обновляться, а список в голосовом канале жил своей жизнью, поэтому связь выглядела
  исправной, и догадаться было почти невозможно.

  Починено с обеих сторон: сервер теперь дожидается входа, прежде чем отвечать на что-либо ещё, а
  приложение просит подписку только после подтверждения и повторяет попытку, если получило отказ.

- **Интерфейс больше не гаснет молча.** Раньше одна ошибка внутри любого элемента экрана убирала всё
  приложение целиком: оставался пустой фон, а голос отваливался вместе с ним. Теперь на этом месте
  появляется понятный экран с описанием, кнопкой перезагрузки и кнопкой «Скопировать отчёт» —
  отчёт сохраняется и переживает перезагрузку, так что его можно прислать и позже.

  Поверх игры такой экран не показывается намеренно: плашка с трассировкой посреди боя хуже, чем
  пропавший виджет.

## 🇬🇧 What's new

- **Root cause found for "the tip sound and overlay stopped working".** A familiar symptom:
  everything works, then suddenly stops, and only a full restart of the app brings it back. The
  culprit was not any single feature but **the order of the first two messages on reconnect**: the
  app introduced itself to the server and immediately, without waiting for a reply, asked to be
  subscribed to events. The server was still verifying the login and rejected the request — and the
  app never listened for that rejection, assuming it was subscribed.

  As a result, **every server update** left a person without all events at once: no tip sound or
  banner, no pinches, no soundboard shots and no new chat messages. The coin balance still updated
  and the voice channel roster still worked, so the connection looked healthy and the cause was
  nearly impossible to guess.

  Fixed on both sides: the server now waits for the login to complete before answering anything
  else, and the app asks for its subscriptions only after confirmation — retrying if refused.

- **The interface no longer goes dark in silence.** Previously a single error inside any part of the
  screen removed the whole app: an empty background remained, and voice dropped with it. Now you get
  a readable screen with the details, a reload button and a "copy report" button — the report is
  saved and survives the reload, so it can be sent later.

  Over a game this screen is deliberately not shown: a stack trace in the middle of a fight is worse
  than a missing widget.
