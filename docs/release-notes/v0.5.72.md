## 🇷🇺 Что нового

Сборка того, что уже было в `v0.5.70` и `v0.5.71`, но до вас не доехало: в тех двух версиях
сломался сборочный конвейер, и установщики просто не собрались. Здесь всё то же самое плюс починка
самого конвейера.

- **🔴 Сообщение с `*курсивом*` вешало приложение.** Любой текст с курсивом, жирным, зачёркнутым или
  спойлером уводил разбор в бесконечный цикл: вкладка съедала память и переставала отвечать — у
  **всех**, кто открывал канал с таким сообщением, а не только у автора. Приехало вместе с
  оформлением сообщений в `v0.5.67`
- **Больше не выкидывает раз в неделю.** Токен жил семь дней от момента входа, поэтому вылетали даже
  те, кто заходит каждый день. Теперь отсчёт идёт от последней активности
- **Предпросмотр ссылок.** Под сообщением со ссылкой — карточка с сайтом, заголовком и описанием.
  Отключается в Настройки → Внешний вид → Ссылки. Картинки в карточке нет намеренно: она заставила
  бы браузер каждого читателя сходить на сторонний сайт и раскрыть ему свой адрес

### Внутреннее

Тесты не запускались на сборочной машине: маска `src/**/*.test.ts` не раскрывалась ни оболочкой,
ни Node 20, а локально на Node 24 работала — поэтому проверка зеленела у разработчика и падала в CI,
а вместе с ней пропускались выкладка и сборка десктопа. Заменено на явные списки файлов.

## 🇬🇧 What's new

This ships what `v0.5.70` and `v0.5.71` already contained but never delivered: the build pipeline
broke in those two, so no installers were produced. Same contents plus the pipeline fix.

- **🔴 A message with `*italics*` froze the app.** Any text with italic, bold, strikethrough or a
  spoiler sent the parser into an infinite loop: the tab ate memory and stopped responding — for
  **everyone** who opened the channel, not just the author. Shipped with message formatting in `v0.5.67`
- **No more weekly logouts.** Tokens expired seven days after login, so даже daily users got kicked
  out. Expiry now counts from last activity
- **Link previews.** A card with site, title and description under messages containing links. Toggle
  in Settings → Appearance → Links. No image, deliberately: it would make every reader's browser
  fetch from the third-party site and reveal their address

### Internal

Tests never ran on the builder: the `src/**/*.test.ts` pattern was expanded by neither the shell nor
Node 20, while it worked locally on Node 24 — so the gate passed for the developer and failed in CI,
skipping deployment and the desktop build along with it. Replaced with explicit file lists.
