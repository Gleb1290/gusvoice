## 🇷🇺 Что нового

- **Свой ник на сервере теперь и правда можно поменять.** Пункт «Изменить ник» в меню при правом
  клике по себе раньше не показывался вовсе — сам механизм был на месте, не было только кнопки. ПКМ
  по себе в списке участников → «Изменить ник · только на этом сервере» (#19, #72)

## 🇬🇧 What's new

- **You can now actually set your per-server nickname.** The "Изменить ник" item in the right-click
  menu on yourself simply didn't appear before — the machinery was all there, only the button was
  missing. Right-click yourself in the member list → "Изменить ник · только на этом сервере" (#19, #72)
