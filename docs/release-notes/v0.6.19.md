## 🇷🇺 Что нового

- **Показ больше не обрывается посреди игры.** В прошлой версии приложение научилось само
  заканчивать трансляцию, когда закрываешь игру, — и оказалось слишком подозрительным: в Dota на
  входе в матч и на выходе из него показ иногда завершался сам собой, хотя игра никуда не делась.
  Дело в том, как задавался вопрос: приложение смотрело, попадается ли окно в списке того, что можно
  показывать, — а в этот список окно не попадает не только когда закрыто, но и когда на секунду
  подвисло на загрузке. Теперь про окно спрашивается напрямую у Windows, и загрузка матча больше не
  выглядит как закрытая игра. Заодно показ не завершится от единственной неудачной проверки — нужны
  две подряд, так что настоящее закрытие игры замечается за двадцать секунд вместо десяти.

- **Приложение для Android снова обновляется.** Три последние версии до телефонов не доезжали:
  сборка падала из-за «ткнуть» — на телефоне мигать окном в панели задач нечем, а код пытался. На
  компьютерах всё это время всё выходило как обычно, поэтому поломка и не бросалась в глаза. Теперь
  на телефон приезжает всё накопившееся сразу: «ткнуть», право «перемещать кого угодно», завершение
  показа при закрытии игры и экономный режим звука с выбором качества на каждый голосовой канал.

## 🇬🇧 What's new

- **Screen sharing no longer cuts out mid-game.** The previous version learned to end a share by
  itself when you close the game — and turned out to be too suspicious: in Dota, entering and leaving
  a match would sometimes end the share even though the game was still running. The problem was the
  question being asked: the app checked whether the window still appeared in the list of things you
  can share, and a window drops out of that list not only when it is closed but also when it briefly
  stops responding while loading. The app now asks Windows about the window directly, so loading into
  a match no longer looks like a closed game. A single failed check no longer ends the share either —
  two in a row are needed, which means a genuine close is noticed in twenty seconds rather than ten.

- **The Android app updates again.** The last three versions never reached phones: the build was
  failing because of "nudge" — there is no taskbar icon to flash on a phone, yet the code tried to.
  Desktop releases kept coming out as usual all that time, which is why the breakage went unnoticed.
  Everything that piled up now arrives at once: nudging, the "move anyone" permission, ending a share
  when the game closes, and the low-bandwidth voice mode with per-channel quality.
