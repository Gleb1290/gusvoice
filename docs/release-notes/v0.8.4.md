## 🇷🇺 Что нового

- **Приложение запускается на компьютерах без видеокарты NVIDIA.** С конца июня десктоп на машинах с AMD или
  встроенной графикой не стартовал вовсе: Windows писал «система не обнаружила nvcuda.dll». Теперь запускается, а
  показ экрана на таких машинах идёт через процессор.
- **Настройки сервера и канала — как остальные настройки.** Разделы стоят списком слева, у каждого есть подпись,
  что внутри. На телефоне сначала открывается список разделов, потом сам раздел.
- **Роли и участники теперь внутри настроек сервера**, отдельного окна больше нет. Кнопка 👥 в шапке списка каналов
  открывает настройки сразу на разделе «Роли».

## 🇬🇧 What's new

- **The app starts on computers without an NVIDIA graphics card.** Since late June the desktop app did not start at
  all on machines with AMD or integrated graphics: Windows reported that nvcuda.dll was not found. It starts now, and
  screen sharing on such machines is encoded on the CPU.
- **Server and channel settings look like the rest of the settings.** Sections are listed on the left, each with a
  line saying what is inside. On the phone the list of sections opens first, then the section itself.
- **Roles and members now live inside server settings**; the separate window is gone. The 👥 button in the channel
  list header opens the settings straight at "Roles".
