## 🇷🇺 Что нового

Релиз про всплывающие окна, которые уезжали за край экрана.

- **Контекстное меню больше не вываливается за экран.** ПКМ по человеку в списке — если участников
  много и список растянут, меню упиралось в нижнюю кромку и низ становился недостижим: доскроллить
  было нечем. Теперь меню не бывает выше экрана, а длинное — прокручивается (#66)
- **Пикер эмодзи держится в окне.** В том числе в узком окне десктопа и на телефоне с поднятой
  клавиатурой, где «низ экрана» на самом деле находится под клавиатурой (#65)
- **Подсказка, как набрать эмодзи.** Задержи курсор на эмодзи в пикере — покажет его код,
  например `:fire:` (#65)
- **`:код:` теперь автозаменяется.** Пишешь `:fire:` — получаешь 🔥 сразу по закрывающему
  двоеточию. Русские сокращения работают: `:огонь:`, `:лайк:`, `:ржу:`. Время `10:30:` и адреса
  вида `http://host:8080:` не трогаются (#65)
- **Сообщение, с которым работаешь, берётся в рамку.** Открыл контекстное меню или пикер реакций —
  видно, к какому именно сообщению это относится. Раньше курсор уходил на меню, подсветка
  наведения слетала и было непонятно (#66)

### Внутреннее
- Арифметика всплывающих слоёв вынесена в общий модуль: три места считали её по-своему и каждое
  ошибалось одинаково — брали `window.innerWidth` (он включает ширину скроллбара) и размеры,
  скопированные из CSS константами (#66)
- В наборе эмодзи теперь паритет: всё, что можно ткнуть в пикере, набирается кодом, и наоборот.
  Добавлена вкладка «Разное» (#65)

## 🇬🇧 What's new

A release about popups that slid off the edge of the screen.

- **Context menus stay on screen.** Right-clicking a member when the list is long used to push the
  menu against the bottom edge, leaving its lower half unreachable with nothing to scroll. Menus are
  now never taller than the viewport, and long ones scroll (#66)
- **The emoji picker stays in the window** — including narrow desktop windows and phones with the
  keyboard up, where the "bottom of the viewport" is actually behind the keyboard (#65)
- **Hover hint for typing emoji.** Rest the pointer on an emoji in the picker and it shows the
  shortcode, e.g. `:fire:` (#65)
- **`:code:` now auto-replaces.** Type `:fire:` and get 🔥 as soon as the closing colon lands.
  Russian aliases work too. Times like `10:30:` and URLs like `http://host:8080:` are left alone (#65)
- **The message you're acting on is framed.** Open its context menu or reaction picker and it's clear
  which message it belongs to — previously the cursor moved to the menu, hover was lost, and the
  connection disappeared (#66)

### Internal
- Popup placement maths moved into one shared module: three call sites each got it wrong the same
  way — using `window.innerWidth` (which counts the scrollbar) and element sizes hardcoded from
  CSS (#66)
- The emoji set now has parity: everything clickable in the picker is typeable by shortcode and
  vice versa, plus a new "Разное" tab (#65)
