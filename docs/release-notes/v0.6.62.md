## 🇷🇺 Что нового

- **Владелец сервера может поднять цену анимированного аватара у себя.** Раньше цена была одна на
  все серверы и её назначал только держатель инстанса. Теперь в «Настройках сервера» → «Экономика»
  у аватара есть поле цены: владелец ставит свою, если его люди зарабатывают больше и аватар у них
  дешевеет. Опустить цену ниже той, что задал держатель инстанса, нельзя — анимация постоянно
  расходует его хранилище и трафик. Кнопка «Вернуть цену инстанса» снимает наценку.

- **Закрыта уязвимость в почтовой библиотеке.** Её разбор адресов можно было замедлить специально
  подобранным длинным списком — это позволяло нагрузить сервер. Библиотека обновлена до исправленной
  версии; на отправку писем обновление не влияет.

## 🇬🇧 What's new

- **A server owner can raise the animated avatar price on their server.** The price used to be the
  same on every server and only the instance holder could set it. Server settings → Economy now has a
  price field for the avatar: an owner can charge more if their members earn more and the avatar has
  become cheap for them. It cannot go below the price set by the instance holder, since the animation
  permanently uses their storage and bandwidth. "Restore instance price" removes the markup.

- **Fixed a vulnerability in the mail library.** Its address parsing could be slowed down on purpose
  with a crafted long address list, which made it possible to load the server. The library has been
  updated to the fixed version; sending mail is unaffected.
