## 🇷🇺 Что нового

- **Иконки серверов.** Настройки сервера → «Основное» → загрузить картинку. В списке слева сервер
  теперь узнаётся по значку, а не по первой букве. GIF остаётся анимированным (#74)
- Правый клик больше не открывает меню браузера с «Печать» и «Сохранить как». Там, где меню нужно —
  в поле ввода, на выделенном тексте, на картинках и ссылках — оно осталось прежним (#75)
- У значков серверов появилось своё меню по правому клику: открыть сервер, отключить его уведомления

### Исправлено
- Участник, которому выдали права только на эмодзи или стикеры, не видел пункта «Настройки сервера» —
  вкладка была, а войти было нельзя. Заодно то же чинилось для прав на звуки, баны, категории и
  доступ к каналам
- Переименование сервера не доезжало до остальных участников до перезагрузки страницы
- Предпросмотр ссылки навсегда пропадал у страниц с необычными символами в заголовке
- В опросе с остатком меньше минуты писалось «осталось 0 мин», а «час и одна минута» показывались
  как «2 ч»
- Порядок ролей мог разъехаться, если при перетаскивании роль случайно попадала в список дважды

## 🇬🇧 What's new

- **Server icons.** Server settings → "Основное" → upload an image. Servers in the left rail are now
  recognisable by their icon instead of a first letter. GIFs keep animating (#74)
- Right-click no longer opens the browser menu with "Print" and "Save as". Where the menu is actually
  useful — text fields, selected text, images and links — it is untouched (#75)
- Server icons got their own right-click menu: open the server, mute its notifications

### Fixed
- A member granted only emoji or sticker permissions could not see the "Настройки сервера" entry —
  the tab existed but there was no way in. The same was fixed for sounds, bans, categories and
  channel access permissions
- Renaming a server did not reach other members until they reloaded the page
- Link previews were permanently lost for pages with unusual characters in the title
- A poll with less than a minute left said "0 min left", and "one hour and one minute" showed as "2 h"
- Role order could break if a role accidentally appeared twice while reordering
