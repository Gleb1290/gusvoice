## 🇷🇺 Что нового

- **Звуки из Soundpad наконец принимаются.** Файлы m4a отвергались, хотя формат значился в списке
  поддерживаемых: тип файла берётся из реестра Windows, и один и тот же звук приезжает то как
  `audio/mp4`, то как `audio/x-m4a`. Теперь тип определяется по самому файлу, а не по подписи, —
  ходить через онлайн-конвертер больше не нужно. (#21)
- **Сначала файл, потом название.** В саундборде кнопка «Выбрать файл» была заперта до ввода
  названия, хотя выбирают наоборот: сперва находят нужную запись среди вороха, а подпись придумывают
  уже под неё. Теперь имя файла ещё и подставляется заготовкой, а негодный файл отсеивается сразу
  при выборе, а не после того, как вы придумали ему имя.
- **В оверлее видно нынешнее лицо.** У купившего анимированный аватар обычный и анимированный —
  разные картинки, и в оверлее оставалась прежняя. Теперь там показывается первый кадр анимации:
  лицо нынешнее, а движения по-прежнему нет — оверлей висит поверх игры.
- **Живой журнал в кошельке.** Пока кошелёк открыт, список операций обновляется сам: раньше баланс
  рос, а список стоял, и это выглядело как «монеты не дошли».

### Исправлено
- Плашка поверх игры писала «типнул кого-то», если человек только что вошёл.
- Исполняемый файл, названный звуком, больше не принимается.

## 🇬🇧 What's new

- **Soundpad clips are finally accepted.** m4a files were rejected even though the format was listed
  as supported: the file type comes from the Windows registry, and the same sound arrives as
  `audio/mp4` for one person and `audio/x-m4a` for another. The type is now determined from the file
  itself — no more round trips through an online converter. (#21)
- **File first, name second.** The soundboard's "choose file" button used to be locked until you
  typed a name, though people work the other way round: find the right clip among many, then name it.
  The file name is now offered as a starting point, and an unusable file is rejected at pick time
  rather than after you have named it.
- **The overlay shows your current face.** For someone with an animated avatar the plain and animated
  pictures are different files, and the overlay kept the old one. It now shows the first frame of the
  animation — current face, still no motion, since the overlay sits on top of a game.
- **A live wallet journal.** While the wallet is open the operation list now updates by itself;
  previously the balance grew while the list stood still, which read as "the coins never arrived".

### Fixed
- The in-game banner said "tipped someone" when the recipient had only just joined.
- An executable renamed to look like a sound is no longer accepted.
