## 🇷🇺 Что нового

- **Показ всего экрана стал стабильнее в играх.** Экран теперь снимается другим способом — тем же, что в OBS, — и
  курсор над игрой больше не дёргается (например, когда перетаскиваете предметы в инвентаре). Показ отдельного окна
  работает как раньше, поэтому для игр сейчас лучше показывать весь экран. На мониторах с HDR картинка в показе может
  выглядеть бледнее.
- **Показывающий меньше страдает от зрителей.** Карточки чужих показов в канале больше не будят у показывающего
  кодирование раз в минуту: превью берётся из маленькой картинки, которую его приложение и так отдаёт.

## 🇬🇧 What's new

- **Full-screen sharing is more stable in games.** The screen is now captured a different way — the same one OBS
  uses — so the cursor over a game no longer stutters (for example, while dragging items in an inventory). Sharing a
  single window works as before, so for games sharing the whole screen is the better choice for now. On HDR monitors
  the stream may look paler.
- **Viewers no longer weigh on the streamer.** Stream cards in a channel no longer wake the streamer's encoder once
  a minute: the preview comes from the small picture their app already sends.
