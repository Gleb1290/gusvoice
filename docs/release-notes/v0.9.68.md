## 🇷🇺 Что нового

- **Саундборд.** Владелец инстанса может включить личные квоты на всех или выбранных серверах. Админ сервера задаёт число звуков на человека. По умолчанию действует прежний общий лимит, его можно изменить в админке инстанса.
- **Хранилище.** В админке видно, сколько места занимают звуки, вложения каналов и оформление каждого сервера. Для саундборда есть разбивка по авторам и прогноз расхода перед включением личных квот.
- **Разовый перенос в закрытый голосовой канал.** Участника может перенести тот, у кого есть право переноса и доступ в целевой канал. Для этого действия принимающему клиенту нужна версия 0.9.68 или новее.
- **Голосовая сцена.** У выключенного микрофона и звука канала появились более крупные контрастные значки.

### Исправлено

- **Android.** Полноэкранный стрим поворачивается вместе с телефоном при включённом системном автоповороте.
- **Windows.** При открытии скачанного файла карточка сразу показывает «Открывается…» и подсвечивает рамку. Быстрые повторные клики больше не запускают несколько окон подряд.

## 🇬🇧 What's new

- **Soundboard.** Instance owners can enable per-user quotas on all or selected servers. Server admins set the number of clips per person. The existing total limit applies by default and can be changed in the instance admin panel.
- **Storage.** The admin panel shows how much space each server uses for sounds, channel attachments, and customization. Soundboard usage is broken down by uploader, with an estimate before enabling per-user quotas.
- **One-time moves into restricted voice channels.** A member with move permission and access to the destination can move someone into it. The receiving client needs version 0.9.68 or newer for this action.
- **Voice stage.** Muted and deafened participants now have larger, higher-contrast icons.

### Fixed

- **Android.** Full-screen streams rotate with the phone when system auto-rotate is enabled.
- **Windows.** Opening a downloaded file shows an immediate status and highlights the card. Rapid repeat clicks no longer launch several windows in succession.
