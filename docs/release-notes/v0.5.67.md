## 🇷🇺 Что нового

Релиз про чат — до него долго не доходили руки.

- **Картинка из буфера.** `Ctrl+V` со скриншотом наконец прикрепляет файл, а не молча ничего не делает.
  Имя даётся по дате (`screenshot-2026-07-20-18-42.png`), иначе у всех в загрузках копились бы
  `image.png`, `image (1).png`, `image (2).png` (#13)
- **Предупреждение о переходе по ссылке.** Клик по чужой ссылке сначала показывает, куда она ведёт:
  крупно домен, ниже полный адрес. Есть две галочки — «не спрашивать про ссылки от этого человека»
  и «не спрашивать вообще». Ссылки на наш же сервер не спрашивают никогда: предупреждать про
  собственный домен — это приучить всех жать «Перейти» не читая (#63)
- **Оформление сообщений.** `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `` `код` ``, блоки ```` ``` ````,
  цитаты через `>` и спойлеры `||текст||` (спойлер раскрывается кликом). Картинок и ссылок с подписью
  намеренно нет: подпись, которая врёт про адрес, — это фишинг (#13)
- **Эмодзи по коду.** Набери `:` и первые буквы — появится список. Русские сокращения работают:
  `:огонь` → 🔥, `:лайк` → 👍, `:ржу` → 🤣 (#14)
- **Разделитель «Новые сообщения».** Заходишь в канал — видно, докуда дочитал в прошлый раз (#15)
- **Авто-«отошёл».** Десять минут без активности — статус сам меняется на «отошёл», при первом
  движении возвращается в «в сети». Ручные «не беспокоить» и «невидимка» не трогает: статус, который
  ты поставил сам, — это заявление, и перебивать его молча нельзя (#16)

## 🇬🇧 What's new

A chat-focused release — this area had been neglected for a while.

- **Paste an image.** `Ctrl+V` with a screenshot in the clipboard finally attaches it instead of silently
  doing nothing. Files are named by date (`screenshot-2026-07-20-18-42.png`) — otherwise everyone's
  downloads folder fills up with `image.png`, `image (1).png`, `image (2).png` (#13)
- **Link interstitial.** Clicking someone else's link first shows where it goes: host in large type, full
  URL below. Two checkboxes — silence it for this author, or silence it entirely. Links to this instance
  never prompt: warning about your own domain just trains everyone to click through without reading (#63)
- **Message formatting.** `**bold**`, `*italic*`, `~~strike~~`, `` `code` ``, ```` ``` ```` blocks,
  `>` quotes and `||spoilers||` (click to reveal). No images and no labelled links, deliberately: a label
  that lies about its destination is the oldest phishing trick there is (#13)
- **Emoji shortcodes.** Type `:` plus a few letters for a picker. Russian aliases work too:
  `:огонь` → 🔥, `:лайк` → 👍, `:ржу` → 🤣 (#14)
- **"New messages" divider.** Opening a channel shows where you left off last time (#15)
- **Auto-away.** Ten minutes idle flips your status to away; the first input flips it back to online.
  Manual "do not disturb" and "invisible" are never touched — a status you set on purpose is a statement,
  and overwriting it silently would be worse than having no auto-away at all (#16)

### Internal
