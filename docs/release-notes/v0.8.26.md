## 🇷🇺 Что нового

- **«Скрыть участников без видео» — и в меню канала.** Правый клик по голосовому каналу в боковой панели → флажок «Скрыть
  участников без видео». Это та же настройка, что кнопка в шапке канала; она своя у каждого и на каждом устройстве.
- **Настройка выключается сама,** когда в канале не остаётся ни стримов, ни камер — вернувшись, вы снова видите всех.

## 🇬🇧 What's new

- **"Hide participants without video" is now in the channel menu too.** Right-click a voice channel in the sidebar → the "Hide
  participants without video" checkbox. It is the same setting as the button in the channel header, and it is personal to each
  user and device.
- **The setting turns itself off** when no streams or cameras are left in the channel, so you see everyone again.
