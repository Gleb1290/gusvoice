## 🇷🇺 Что нового

- **Исправлено: в десктопе не было вкладки «Монеты»**, хотя экономика на сервере включена — в
  браузере при этом всё показывалось. Приложение запоминало возможности сервера в тот момент, когда
  вы его добавляли, и больше об этом не спрашивало: сервер, добавленный до появления монет, о них
  так и не узнавал. Теперь приложение узнаёт о включённых возможностях при каждом входе.
- **Исправлено: настройки экономики не открывались на сервере, где её ещё ни разу не включали** —
  вкладка бесконечно показывала «Загрузка…». Владелец теперь видит настройки с обычными значениями
  и может включить монеты первым же переключателем.

## 🇬🇧 What's new

- **Fixed: the "Coins" tab was missing in the desktop app** even with the economy enabled on the
  server, while the browser showed it fine. The app recorded what a server could do at the moment you
  added it and never asked again, so a server added before coins existed never learned about them. It
  now picks up enabled features on every sign-in.
- **Fixed: economy settings wouldn't open on a server where they had never been configured** — the
  tab showed "Loading…" forever. The owner now sees the settings pre-filled with the usual values and
  can switch coins on right there.
