## 🇷🇺 Что нового

- **🔴 Приватные каналы стали действительно приватными.** Сообщения закрытого канала уходили по сети
  **всем участникам сервера** — приложение их не показывало, но данные до чужого компьютера уже
  доехали, и увидеть их можно было, просто открыв инструменты разработчика. Теперь сервер считает,
  кто имеет право видеть канал, и отправляет сообщение только им.
  - Это же касается правок, удалений и реакций в закрытом канале.
  - Заодно исправлено: **исключённый с сервера продолжал получать сообщения**, пока не перезапустит
    приложение. Теперь поток прекращается сразу, а его самого уводит в личные сообщения.

- **Можно выйти с сервера.** Раньше уйти было нельзя вообще — только попросить кого-нибудь себя
  выгнать. Пункт «Покинуть сервер» появился в меню по правой кнопке на иконке сервера.
  - Владельцу выходить нельзя: сначала передайте владение или удалите сервер.
  - Вернуться потом можно по приглашению — бан при выходе не ставится.

- **Список участников обновляется сразу.** Кик, бан, разбан, вход по приглашению и удаление аккаунта
  раньше не доходили до остальных в реальном времени: список менялся только после перезахода.

- **Адрес сервера со скопированным путём теперь находится.** При первом запуске приложение принимает
  адрес в том виде, в каком его обычно копируют из адресной строки браузера — с путём и параметрами.
  Раньше на полностью рабочий сервер отвечало «проверьте адрес».

- **«Печатает…» больше нельзя подделать.** Посторонний мог показать себя печатающим в чужом сервере
  и постучаться в личные сообщения к человеку, с которым не переписывался.

- **Под капотом:** проверка ссылок на вложения стала строже, а число автоматических тестов выросло с
  429 до 619 — в том числе на двухфакторную авторизацию и права доступа к каналам, где их не было
  вовсе.

## 🇬🇧 What's new

- **🔴 Private channels are actually private now.** Messages from a restricted channel were sent over
  the network **to every member of the server** — the app didn't display them, but the data had
  already reached other people's machines, and opening developer tools was enough to read it. The
  server now works out who may see a channel and delivers only to them.
  - The same applies to edits, deletions and reactions in a restricted channel.
  - Fixed alongside it: **a kicked member kept receiving messages** until they restarted the app.
    The stream now stops immediately and they are taken back to direct messages.

- **You can leave a server.** Until now there was no way out at all — you had to ask someone to kick
  you. "Leave server" is in the right-click menu on the server icon.
  - The owner can't leave: transfer ownership or delete the server first.
  - You can come back later with an invite — leaving does not ban you.

- **The member list updates immediately.** Kicks, bans, unbans, joining by invite and account
  deletion didn't reach everyone else in real time: the list only changed after a restart.

- **A server address pasted with a path now works.** On first launch the app accepts the address in
  the form people actually copy from a browser's address bar — path and query included. It used to
  answer "check the address" for a perfectly working server.

- **"Typing…" can no longer be faked.** An outsider could appear to be typing in someone else's
  server and knock on the direct messages of a person they had never talked to.

- **Under the hood:** attachment link validation is stricter, and the automated test count grew from
  429 to 619 — including two-factor authentication and channel access rights, which had none at all.
