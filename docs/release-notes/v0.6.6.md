## 🇷🇺 Что нового

- **Сообщения с других серверов больше не теряются** (#80). Раньше приложение слушало только тот
  сервер, который открыт у вас на экране: написанное на остальных не приходило вообще — ни
  уведомлением, ни счётчиком непрочитанных. Хуже того, открыв такой сервер позже, вы не находили
  сообщение и в самом канале. Теперь клиент слушает все ваши серверы сразу.
  - На иконке сервера в левом столбце появляется число непрочитанных, если сервер не открыт.
    Упоминания выделяются ярким значком, обычные сообщения — приглушённым.
  - История канала обновляется при каждом открытии. Пропущенное по дороге сообщение больше не
    оставляет дыру в переписке до перезапуска приложения.
- **Системные уведомления теперь включены по умолчанию** — в режиме «Упоминания и ЛС». Раньше они
  молчали, пока человек сам не найдёт настройку, и выглядело это сломанной функцией. Режим
  «Все сообщения» и полное выключение — там же, в настройках.
- **Браузер больше не проглядывает сквозь приложение** (#81). Ctrl+P открывал диалог печати чата,
  Ctrl+J — панель загрузок браузера, а правый клик по ползунку громкости и по панели инстансов
  показывал меню с «Сохранить как» и «Отправить вкладку на свои устройства». В настольном приложении
  всё это отключено целиком.
  - В полях ввода теперь своё меню: Вырезать, Копировать, Вставить, Выделить всё — вместо родного,
    которое приносило с собой «Импорт паролей».
  - Привычное не пострадало: Ctrl+C/V/X/A, Ctrl+F (поиск по сообщениям), Ctrl+R и F12 работают.

## 🇬🇧 What's new

- **Messages from other servers no longer go missing** (#80). The app used to listen only to the
  server currently on your screen — anything posted elsewhere never arrived at all: no notification,
  no unread count. Worse, opening that server later didn't show the message in the channel either.
  The client now listens to all of your servers at once.
  - A server icon in the left rail shows an unread count while that server isn't open. Mentions get
    the bright badge, ordinary messages a muted one.
  - Channel history refreshes every time you open a channel, so a message lost in transit no longer
    leaves a hole in the conversation until you restart the app.
- **System notifications are now on by default**, set to "mentions and DMs". They used to stay
  silent until you found the setting yourself, which read as a broken feature. "All messages" and
  turning them off are in the same place.
- **The browser no longer shows through the app** (#81). Ctrl+P opened a print dialog for the chat,
  Ctrl+J the browser's downloads panel, and right-clicking the volume slider or the instances panel
  offered "Save as" and "Send tab to your devices". The desktop app disables all of it outright.
  - Text fields get their own menu — Cut, Copy, Paste, Select all — instead of the native one that
    came with "Import passwords" attached.
  - Nothing familiar was lost: Ctrl+C/V/X/A, Ctrl+F (message search), Ctrl+R and F12 still work.
