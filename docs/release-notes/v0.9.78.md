## 🇷🇺 Что нового

- В каналах, где вам нельзя писать, вместо поля сообщения видна плашка «Только для чтения». Когда администратор меняет ваши права, поле исчезает или появляется прямо в открытом чате. (#269)
- На Android ссылки из сообщений и их превью открываются во внешнем браузере. Жестом «Назад» можно вернуться в переписку. (#270)

## 🇬🇧 What's new

- Read-only channels now show a “Read only” notice in place of the message box. If an admin changes your permissions, the box appears or disappears while the chat is open. (#269)
- On Android, links in messages and link previews open in your external browser. Use the back gesture to return to the chat. (#270)
