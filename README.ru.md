GusVoice — закрытое место для общения компании друзей, сообщества или небольшой команды: **серверы → категории → текстовые и
голосовые каналы** с ролями как в Discord, плюс **личные сообщения как в Telegram** — голосовые, кружки, опросы, звонки,
папки. Весь звук и видео идут через собственный **[LiveKit](https://livekit.io) SFU** на вашем сервере: прямых соединений
между участниками нет, и чужой IP-адрес никому не виден. Весь стек поднимается **одним `docker compose`**, установщик сам
генерирует все секреты, а веб, Windows и Android подключаются к *вашему* серверу.

## Возможности

**🎙️ Голос и показ экрана**
- Голосовые каналы с живым списком «кто говорит»; громкость каждого участника, рация (push-to-talk), глобальные клавиши микрофона и звука на компьютере.
- Шумоподавление — системное, **RNNoise** или **DeepFilter**, — эхоподавление и автоусиление.
- Показ экрана в родном разрешении до 4K, 15/30/60 кадров, «Чёткость» или «Плавность»; зритель сам выбирает качество.
- На Windows показ нативный, с аппаратным кодированием (NVENC) и звуком приложений, а приложение не перерисовывается, пока его закрывает игра.
- Всё медиа идёт через сервер — без P2P и без раскрытия IP.

**🏠 Серверы, каналы, роли**
- Серверы → категории → текстовые и голосовые каналы; приглашения ссылкой со сроком и лимитом.
- Роли и права как в Discord, с исключениями на категорию и канал; модерация голоса; журнал аудита.
- Ответы, реакции, @упоминания (включая `@everyone`), закрепы, вложения, поиск, свои эмодзи и звуки сервера.
- По желанию: монеты сервера с магазином и саундбордом, статус «Играет в …».

**💬 Личные сообщения как в Telegram**
- Пузыри, альбомы до 10 фото и видео, ответ на фрагмент, пересылка в несколько бесед, закреп сообщений и бесед.
- Голосовые до 30 минут (1× / 1,5× / 2×, «прослушать один раз») и видеосообщения-кружки.
- Звонки один на один — голос, видео, показ экрана; на Android входящий звонок на весь экран даже на заблокированном телефоне.
- Группы, «Избранное», опросы и викторины, геопозиция и трансляция геопозиции, контакты, файлы до 512 МБ с докачкой.
- Папки и архив, черновики на всех устройствах, «Отправить позже» и «Когда будет в сети», отправка без звука, «Без звука» на любой срок.
- Мгновенный запуск из кеша на устройстве; неотправленное уходит само, когда вернётся сеть.
- Приватность: кто видит время захода, кто может писать и звонить, плашка незнакомца с «Пожаловаться» и «Заблокировать».

**🌐 Федерация** *(по умолчанию выключена)*
- Свяжите свой сервер с сервером друга: связку подтверждают оба администратора, каждый сервер подписывает запросы своим ключом.
- Люди с соседнего сервера заходят к вам **со своим аккаунтом** по ссылке-приглашению; все их серверы — в одной боковой панели.
- Личные сообщения между серверами (`@имя@сервер`), включая группы, звонки и файлы; переписка продолжается, даже если одна из сторон недоступна.

**📱 Клиенты**
- Веб, **Windows** с автообновлением (трей, глобальные клавиши, уведомления как в Telegram Desktop) и **Android**.
- Адрес своего сервера вводится при входе; переключаться между серверами можно в любой момент.

**🗺️ Своя карта** — геопозиция в ЛС рисуется по выгрузке OpenStreetMap с *вашего* сервера; клиенты не обращаются к сторонним картам. См. [docs/maps.md](docs/maps.md).

**🔔 Пуши без Google** — ЛС и упоминания будят приложение на Android через [UnifiedPush](https://unifiedpush.org) и шлюз [ntfy](https://ntfy.sh) из комплекта — без Firebase и сервисов Google Play.

**🔄 Обновление одной кнопкой** — админ-панель сама показывает, что вышла новая версия; кнопка **«Обновить»** сохраняет копию базы и обновляет сервер — без консоли и SSH. Приложения для Windows и Android обновляются сами.

**🔒 Безопасно по умолчанию** — секреты генерируются при установке, конфигурация с отказом по умолчанию, ограничение попыток входа, 2FA, политика регистрации (открытая, с одобрением, по приглашениям).

## Быстрый старт

Понадобятся:

- **Linux-сервер** — хватит небольшого VPS (2 vCPU / 4 ГБ RAM / 20 ГБ диска для начала);
- **домен** — GusVoice использует шесть поддоменов: `voice` · `api` · `presence` · `lk` · `media` · `ntfy`;
- открытые порты **80** и **443**, плюс медиа LiveKit **7881/tcp** и **7882/udp**;
- **Docker** — если его нет, установщик предложит поставить.

```bash
curl -fsSL https://raw.githubusercontent.com/Gleb1290/gusvoice/main/install.sh | bash
```

Хотите сначала прочитать скрипт?

```bash
git clone https://github.com/Gleb1290/gusvoice.git
cd gusvoice
./install.sh
```

Установщик задаст несколько вопросов, **сгенерирует все секреты**, запишет `.env` и поднимет стек за Caddy из комплекта с
автоматическим HTTPS от Let's Encrypt — или за вашим обратным прокси (Nginx Proxy Manager, nginx, Traefik; он спросит). В конце
он напечатает нужные **DNS-записи** и **проброс портов**.

Затем откройте `https://voice.<ваш-домен>` и введите **код установки**, который напечатал установщик: короткий мастер в
браузере создаст аккаунт администратора и задаст название, почту, правила регистрации и первый сервер со ссылкой-приглашением.

Подробно — DNS, свой прокси, подключение приложений — в **[docs/SELF-HOSTING.md](docs/SELF-HOSTING.md)** (на английском).

## Архитектура

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="docs/readme/architecture-dark.svg">
  <img alt="Архитектура GusVoice" src="docs/readme/architecture-light.svg" width="100%">
</picture>

- **backend** (Node.js, Fastify, Drizzle/PostgreSQL) — аккаунты, серверы, каналы, роли, сообщения и ЛС, шлюз реального времени и **токены LiveKit**: что вам можно публиковать, решают ваши права.
- **livekit-server** — SFU; через него идут голос, видео и показ экрана (`7882/udp`, запасной `7881/tcp`). Режима P2P нет.
- **presence** — принимает вебхуки LiveKit и рассказывает всем клиентам, кто в каком голосовом канале.
- **client** — веб-приложение на React; приложения для Windows (Tauri) и Android — оболочки вокруг того же кода.
- **PostgreSQL** + **Redis** — данные и рассылка событий, **versitygw** — файлы (S3 API), **ntfy** — пуши, **Caddy** — TLS.

Подробнее об устройстве — **[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)** (на английском).

## Обновление

**Из админ-панели — основной способ.** Вкладка **«Инстанс»** показывает установленную и новейшую версии; кнопка
**«Обновить»** делает копию базы и обновляет сервер по шагам, ход виден прямо в панели. Установщик включает кнопку сам, если
запущен от root или `sudo` без пароля; иначе он в конце подскажет одну команду — `sudo ./update.sh --install-updater`.
Доступа к Docker у бэкенда нет: он оставляет заявку, которую подхватывает маленький сторож systemd на хосте.
Приложения для Windows и Android обновляются сами.

**Из консоли** — то же самое одной командой:

```bash
cd gusvoice
./update.sh
```

`update.sh` сохраняет копию `docker-compose.yml` и `config/`, обновляет их до последнего релиза, скачивает новые образы,
**делает копию базы** в `./.gusvoice-backups/` и пересоздаёт только изменившиеся контейнеры. `.env` и данные не трогаются;
миграции базы применяются сами при запуске.

| Флаг | Что делает |
|------|------------|
| `--images-only` | Только скачать образы и пересоздать — `docker-compose.yml` / `config/` не трогать. |
| `--prune` | Удалить старые неиспользуемые образы. |
| `--no-db-backup` | Не делать копию базы. |
| `--install-updater` | (root, systemd) Включить кнопку **«Обновить»** в админ-панели. |
| `-y`, `--yes` | Без вопросов. |


## Удаление

```bash
./uninstall.sh            # остановить и удалить контейнеры — данные сохраняются
./uninstall.sh --purge    # спросит «yes», затем удалит тома с данными и .env
```

## Где что лежит

| Что | Где |
|-----|-----|
| Настройки и **все секреты** | `.env` (пишет установщик, `chmod 600` — не коммитить) |
| База, файлы, пуши, сертификаты | именованные тома Docker (`gusvoice_pgdata`, `gusvoice_s3data`, `gusvoice_ntfydata`, `gusvoice_caddydata`, …) |
| Конфиг прокси и SFU | `config/Caddyfile`, `config/livekit.yaml` (берут значения из `.env`) |
| Копии перед обновлением | `./.gusvoice-backups/<время>/` |

## Сборка из исходников

По умолчанию ставятся готовые образы, но в compose-файле у каждого сервиса есть секция `build:`:

```bash
git clone https://github.com/Gleb1290/gusvoice.git && cd gusvoice
./install.sh                 # создаёт .env и поднимает стек
docker compose build         # собрать образы из этих исходников
docker compose up -d
```

Работа с самим кодом (Node.js, pnpm, проверка типов, тесты, приложение для компьютера на Rust) — **[CONTRIBUTING.md](CONTRIBUTING.md)**.

```
packages/shared      битовое поле прав, типы DTO, протокол WebSocket
packages/backend     REST + шлюз + токены LiveKit (Fastify, Drizzle)
packages/presence    вебхуки LiveKit → Redis → presence по WebSocket
apps/client          веб-приложение на React (оно же внутри приложений для Windows и Android)
apps/desktop         оболочка Tauri v2 для Windows и Android
config/              конфиги LiveKit и Caddy (без секретов)
docker-compose.yml   весь стек
```
